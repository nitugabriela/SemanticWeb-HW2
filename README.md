# Book Recommender - Semantic Web Homework 2

A web application for book recommendations using RDF, OWL, SPARQL, and a RAG-based AI chatbot.

## Team Members

### Nitu-Sararu Ramona-Gabriela
- **Exercise 1** – Wrote the RDF/XML file modeling the book recommendation scenario (users Alice and Bob, books Dune, The Silent Patient, Hunger Games, Harry Potter with themes, reading levels and authors)
- **Exercise 7** – Built the RAG chatbot:
  - Floating chat widget present on all pages of the website
  - Context-aware conversation starters (different starters on home page, book list page, and individual book pages)
  - LLM responses enhanced with data from a vector database built from the RDF file (books, authors, themes, user preferences)
  - Author + theme book search (e.g. "What book has the author Frank Herbert and the theme Science Fiction?" - Dune)
  - Used LM Studio with Gemma 3 4B local model for inference

### Precup Cristiana-Florentina
- **Exercise 2** – RDF/XML upload and graph visualization using JUNG
- **Exercise 3** – Add and edit books using Jena API
- **Exercise 4** – Book list page and individual book detail pages using Jena API
- **Exercise 5** – OWL ontology for the book recommendation system, visualized in GraphDB
- **Exercise 6** – 5 SPARQL queries for the ontology, executed in Protégé/GraphDB
